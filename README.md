# Algorithme-C

Exercices d'algorithmique et de structures de données résolus en **C**.
Les énoncés appartiennent à leurs auteurs et à leurs établissements.

## Structure du dépôt

```text
algorithme-c/
├── dauphine/ 
├── ensiie/
├── hackerrank/
└── README.md
```

## Démarrage

### Prérequis

- Un compilateur C (`gcc` ou `clang`)

### Compiler et exécuter un exercice

```bash
gcc -Wall -Wextra -std=c99 -o exo chemin/vers/exercice.c
./exo
```
